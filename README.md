# Portfólio - Leandro Goulart

Portfólio profissional focado em Sistemas de Informação, UX/UI e Design Digital.

## Como abrir no computador
Abra o arquivo `index.html` no navegador.

## Como publicar grátis no GitHub Pages
1. Crie uma conta em https://github.com caso ainda não tenha.
2. Crie um repositório chamado `portfolio-leandro`.
3. Envie `index.html`, `styles.css` e `script.js` para o repositório.
4. Vá em Settings > Pages.
5. Em Source, escolha `Deploy from a branch`.
6. Selecione a branch `main` e a pasta `/root`.
7. Salve. O GitHub mostrará o endereço público do site.

## O que editar primeiro
- Adicionar seu GitHub quando criar a conta/repositórios.
- Substituir projetos conceituais por projetos reais conforme forem concluídos.
- Adicionar imagens e protótipos ao case de UX/UI.
- Adicionar botão para baixar o currículo.
- Revisar tecnologias para listar apenas as que você realmente utiliza.
