DEMONSTRAÇÃO TÉCNICA

Modelagem e consultas SQL

Trechos de implementação usados para demonstrar como o projeto sairia da modelagem e chegaria às consultas do sistema.

CREATE TABLE clientes (
  id_cliente INT PRIMARY KEY AUTO_INCREMENT,
  nome VARCHAR(120) NOT NULL,
  email VARCHAR(150) UNIQUE
);

CREATE TABLE projetos (
  id_projeto INT PRIMARY KEY AUTO_INCREMENT,
  id_cliente INT NOT NULL,
  titulo VARCHAR(150) NOT NULL,
  prazo DATE,
  status VARCHAR(30),
  valor DECIMAL(10,2),
  FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente)
);
SELECT
  c.nome AS cliente,
  p.titulo AS projeto,
  p.prazo,
  p.valor
FROM projetos p
JOIN clientes c ON c.id_cliente = p.id_cliente
WHERE p.status = 'Em andamento'
ORDER BY p.prazo ASC;

CASE PRINCIPAL

UX RESEARCH • UX/UI • ESTUDO DE CASO

Redescoberta de ofertas em aplicativo de delivery

Estudo sobre a dificuldade de recuperar uma promoção após o usuário continuar comparando restaurantes e preços.

Objetivo Facilitar o retorno a ofertas já visualizadas sem interromper a comparação.
01Observação

A promoção vista anteriormente pode desaparecer durante a navegação.

02Entrevistas

Perguntas sobre escolhas, promoções, comparação de preços e comportamento após encontrar uma oferta.

03Padrões

Usuários continuam comparando preços mesmo depois de encontrar uma oferta interessante.

04Insight

Existe necessidade de recuperar facilmente uma opção vista antes da comparação.

05Hipótese

Registrar ofertas visualizadas pode reduzir a frustração e melhorar a tomada de decisão.

06Próxima fase

Fluxo, wireframes, protótipo e testes para validar a solução.
